# jogoMarioHTML
# 🕹️ Projeto Acadêmico: Jogo do Mario com HTML, CSS e JavaScript

Este repositório contém um projeto acadêmico desenvolvido como parte do processo de aprendizado em desenvolvimento web. O projeto consiste em um jogo simples baseado no clássico **Super Mario**, implementado com **HTML**, **CSS** e **JavaScript puro**.

> ❗ Este projeto foi criado com fins educacionais, com base no conteúdo do vídeo original disponível no Youtube. Todos os créditos de concepção e ideia são do autor do vídeo referenciado.


## 🎮 Descrição do Jogo

O jogo consiste em controlar o Mario enquanto ele corre automaticamente pelo cenário. O jogador deve pressionar uma tecla (geralmente **barra de espaço**) para fazer o Mario pular e evitar obstáculos como canos. Se o Mario colidir com um obstáculo, o jogo termina e pode ser reiniciado.

Este projeto é uma excelente introdução à manipulação de elementos DOM, animações com CSS e lógica básica com JavaScript.

Para executar este projeto localmente, você precisará de:

- Um navegador moderno (Google Chrome, Firefox, Edge, etc.)
